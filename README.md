# automation

Скрипты для автоматизации задач в Linux (курс IW).

- `lab01/` — бэкап папки в tar.gz
- `lab02/` — скрипт на Python: курс валют на дату из локального API, сохранение в JSON
- `lab03/` — cron в Docker: скрипт из lab02 сам запрашивает курсы каждое утро и по пятницам
- `lab04/` — журнал оценок gradebook: его PHPUnit-тесты гоняет Jenkins на отдельном SSH-агенте
