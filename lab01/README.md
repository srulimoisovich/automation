# backup.sh

**Назначение:** скрипт делает резервную копию каталога в архив `tar.gz`. Имя архива: `<имя_каталога>_<дата>.tar.gz`, дата в формате `ГГГГ-ММ-ДД`. В архив попадает сам каталог, без абсолютных путей.

**Запуск:**

```bash
chmod +x backup.sh
./backup.sh <каталог_источник> [каталог_назначения]
```

Второй аргумент необязательный, по умолчанию `/backup`. Если каталог не найден, скрипт пишет ошибку в stderr и завершается с кодом 1.

**Пример:**

```console
$ sudo ./backup.sh /etc/nginx
saved /backup/nginx_2026-10-21.tar.gz
$ ./backup.sh /etc/nginx /opt/bak
saved /opt/bak/nginx_2026-10-21.tar.gz
```

Примечание: каталог назначения должен существовать (например, `sudo mkdir /backup`).
