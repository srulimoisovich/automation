# backup.sh

Ещё одна вариация скрипта резервного копирования. Оформлена в более
`pushd`/`popd` перед архивацией.

## Использование

```bash
chmod +x backup.sh
bash backup.sh <DIR_SRC> [DIR_DST]
```

- **`DIR_SRC`** — папка, которую нужно сохранить (обязательный
  аргумент; если не передан, скрипт сразу завершится с ошибкой).
- **`DIR_DST`** — куда положить архив (необязательный аргумент, по
  умолчанию `/backup`).

## Примеры

```bash
bash backup.sh ~/projects/myapp ~/backups
bash backup.sh ~/projects/myapp
```

## Формат имени архива

```
<имя_папки>.<ДД-ММ-ГГГГ_ЧЧММСС>.tar.gz
```

Например: `myapp.14-09-2026_172311.tar.gz`

Обратите внимание: здесь дата в формате день-месяц-год, в отличие
от других вариаций.

## Проверки и обработка ошибок

- Если аргумент `DIR_SRC` не передан вовсе, bash сразу выводит
  сообщение об ошибке (используется конструкция `${1:?...}`) и
  скрипт завершается.
- Если папка-источник не существует — выводится сообщение в stderr,
  код завершения `2`.
- Если папки назначения нет — скрипт пытается создать её (`mkdir -p`).
- Если нет прав на запись в папку назначения — ошибка, код `2`.
- Если `tar` завершился с ошибкой — сообщение об ошибке, код `1`, а
  недописанный архив удаляется.

## Технические детали

Перед архивацией скрипт временно переходит в родительскую папку
источника через `pushd`, чтобы `tar` работал с относительным путём
(это исключает попадание лишних вложенных папок в архив), а затем
возвращается назад через `popd`.

## Требования

- Bash
- Утилиты `tar`, `date`, `mkdir`, `basename`, `dirname`, `pushd`/`popd`
  (все входят в стандартный Bash)
